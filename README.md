# 标引 SIGN

把 CSV / Excel 的每一行摊成一页表单来标注。列名变成字段，能识别出的可选项变成单选或多选，填完后写回原来的列。

## 启动

需要 Node.js。

```bash
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:5173/ 。没有文件时可以点「载入示例」。

```bash
npm run build
npm run preview
```

## 使用

1. 选择 CSV、XLS、XLSX 或 XLSM，或把文件拖进页面。
2. 每一页对应源表中的一行。长文本在最上面，其余字段两列并排。
3. 填完用「写回源文件」或 `Ctrl/Cmd + S`。
4. 左右方向键、PageUp / PageDown 翻页。正在输入时用 `Alt + 方向键`。

Chrome / Edge 用「选择文件」打开后，可以直接覆盖源文件。拖入的文件和示例没有文件句柄，保存时会下载。

离开页面前如果还有未写回的修改，浏览器会提示。

## 列如何变成表单

识别顺序：

| 来源 | 写法 |
| --- | --- |
| 表头 | `学科[计算机\|生物\|物理]` 为单选，`标签{甲\|乙}` 为多选。中文括号、顿号、逗号也可以分隔。 |
| 数据验证 | Excel 单元格的列表验证（含 x14）。 |
| 选项表 | 工作表名叫 `选项`、`可选项`、`选项表`、`字典`、`options` 或 `配置`。可以是「字段 + 选项」两列，也可以每一列是一组选项。 |
| 取值归纳 | 列里重复出现的短文本，或成套的「是/否」「有/无」等。 |

选项表本身不会被当作待标注的数据表，也不会自动加上「打标结果」。

另外：

- **打标结果**：没有这一列时会补上。单选「是（1）」「否（0）」，写入 `1` 或 `0`。已有的「是」「否」会在点选时改写成 `1` / `0`。
- **ID 列不显示**：列名像 `id`、`uid`、`uuid`、`guid`、`编号`、`序号`、`主键`，或取值全是不重复的 UUID / 长数字。列仍留在文件里。
- **版本号只读**：列名像 `版本号`、`版本`、`version`，或取值都像 `3.2.0`。只展示，不写回。
- **长文本**：超过约 42 字或含换行的文本列放在表单顶部，全文展开，不计入完成度。
- **HTML**：单元格里有 HTML（或 `&lt;b&gt;` 这类转义）时按标签排版。字体颜色统一为白色，加粗、斜体等保留。脚本和 `javascript:` 链接会被去掉。需要改字时点「编辑原文」。

格式检查会标出 Excel 错误值、首尾空白、不可见字符、制表符、打标结果不是 `1`/`0`、单选值不在可选项内，以及重复的字段名。

## 写回

- XLSX / XLSM：在原压缩包里改单元格，尽量保留数据验证和样式。
- CSV：按 UTF-8（带 BOM）重写。读入时若 UTF-8 出现大量替换字符，会尝试按 GBK 解码。
- XLS：用表格库重建，复杂格式可能变化。

只有改过的工作表才会补写「打标结果」表头。
